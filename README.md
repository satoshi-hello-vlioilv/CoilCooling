# アルミニウムコイル 冷却シミュレータ（3D・横置き片側送風）

巻き取られたアルミニウムコイルの冷却過程を、3Dモデルで可視化するブラウザアプリです。
単一の `index.html` で動作します（追加のビルド・インストール不要）。

![type](https://img.shields.io/badge/type-single--file%20HTML-blue) ![3D](https://img.shields.io/badge/3D-Three.js-orange)

## 使い方

1. `index.html` をモダンブラウザ（Chrome / Edge / Firefox / Safari）で開く
2. 「▶ 再生」を押すと冷却シミュレーションが始まります
3. マウスで回転・ズーム（ドラッグ／ホイール）
4. 「断面 表示」ボタンで切り欠き、内部（半径×幅の2次元温度場）を確認できます

> 3D描画ライブラリ Three.js を CDN（unpkg.com）から読み込むため、初回はインターネット接続が必要です。

## 形状・配置

- **ドーナツ型円柱**（バウムクーヘン／トイレットペーパー状の中空円筒）
- **横置き（eye-to-wall）**：コイル軸を水平にし、外周面を下にして設置
- **片側送風**：一方のフラット面（=風上面）に風を当てて冷却。送風方向は3D矢印で表示

## 特長

- **温度カラーマップ**：青（低温）→赤（高温）
- **非対称冷却の可視化**：風上面が先に冷え、風下面・中心ほど冷えにくい様子が分かります
- **2次元・異方性 物理モデル**：半径方向と幅(軸)方向の熱伝導を別々に扱います
- **温度推移グラフ**：中心・風上面・風下面の温度変化をリアルタイム表示
- **可変パラメータ**：合金種・初期/周囲温度・送風強さ（熱伝達係数 h）・
  半径方向 実効熱伝導率 kᵣ・幅方向 熱伝導率 k_z・放射率・コイル寸法（外径/内径/幅）・計算速度

## 物理モデルの概要

コイルを半径方向 `NR=24`・幅(軸)方向 `NZ=16` のセルに分割した
**軸対称2次元有限体積法**で、各セルの熱収支を陽解法で時間積分します。

- **熱伝導（異方性）**：フーリエの法則
  - 半径方向 `Q = kᵣ · A · ΔT / dr`
  - 幅(軸)方向 `Q = k_z · A · ΔT / dz`
- **表面の放熱**：対流＋放射 `Q = [ h·(T − T∞) + ε·σ·(T⁴ − T∞⁴) ] · A`
- **片側送風の非対称境界条件**（風上面の h を基準とした比率）
  - 風上面 1.0 ／ 風下面 0.25 ／ 外周面 0.55 ／ 巻芯(内周) 0.40
- **熱伝導率の異方性**：
  - 半径方向 kᵣ：巻き重なり部の空気層・酸化皮膜により実効値は無垢材より大幅に低下（既定 3 W/m·K）。
    → 「中心が冷えにくい」主因
  - 幅方向 k_z：幅方向は連続金属のため伝導が速い（既定はおおむね無垢材値）。
    → 軸方向の温度差は相対的に小さくなります（物理的に妥当な挙動）。値を下げると軸方向差が顕著に
- 時間刻みは安定条件から自動決定し、計算速度に応じてサブステップ化します

| A1100 | 2710 | 904 | 222 |
| A3003 | 2730 | 893 | 160 |

| A6061 | 2700 | 896 | 167 |

## 注意

本シミュレータは教育・可視化を目的とした簡易モデルです。実機の冷却時間・温度を厳密に
予測するものではありません（巻き方向の循環流、接触熱抵抗の分布、相変化、ふく射の形態係数等は
簡略化しています）。
