# アルミニウムコイル 冷却シミュレータ（3D）

巻き取られたアルミニウムコイルの冷却過程を、3Dモデルで可視化するブラウザアプリです。
単一の `index.html` で動作します（追加のビルド・インストール不要）。

![type](https://img.shields.io/badge/type-single--file%20HTML-blue) ![3D](https://img.shields.io/badge/3D-Three.js-orange)

## 使い方

1. `index.html` をモダンブラウザ（Chrome / Edge / Firefox / Safari）で開く
2. 「▶ 再生」を押すと冷却シミュレーションが始まります
3. マウスで回転・ズーム（ドラッグ／ホイール）。切り欠き断面から内部の温度勾配が見えます

> 3D描画ライブラリ Three.js を CDN（unpkg.com）から読み込むため、初回はインターネット接続が必要です。

## 特長

- **3Dモデル**：中空円筒（コイル）をくさび状に切り欠き、内部の温度分布を断面で可視化
- **温度カラーマップ**：青（低温）→赤（高温）。コイル中心ほど冷えにくい様子が一目で分かります
- **物理モデル**：半径方向の熱伝導（有限体積法）＋ 外周・内周・端面からの対流・放射冷却
- **温度推移グラフ**：中心温度と表面温度の時間変化をリアルタイム表示
- **可変パラメータ**：合金種・初期/周囲温度・冷却方法（自然空冷／強制空冷／ミスト／水焼入れ）・
  熱伝達係数 h・半径方向 実効熱伝導率 k・放射率・コイル寸法（外径/内径/幅）・計算速度

## 物理モデルの概要

コイルを半径方向に `N=30` 個のセルに分割し、各セルの熱収支を陽解法で時間積分します。

- **半径方向 熱伝導**：フーリエの法則（円筒座標）
  `Q = k · A · (Tᵢ₋₁ − Tᵢ) / dr`
- **表面・端面の放熱**：対流＋放射
  `Q = [ h·(T − T∞) + ε·σ·(T⁴ − T∞⁴) ] · A`
- **実効熱伝導率 k**：巻き重なり部の空気層・酸化皮膜により、コイル半径方向の実効値は
  無垢アルミ（約 237 W/m·K）より大幅に低下（既定 3 W/m·K）。これが「中心が冷えにくい」主因です
- 時間刻みは安定条件から自動決定し、計算速度に応じてサブステップ化します

### 既定の合金物性

| 合金 | 密度 ρ [kg/m³] | 比熱 cp [J/kg·K] |
|------|------|------|
| A1100 | 2710 | 904 |
| A3003 | 2730 | 893 |
| A5052 | 2680 | 880 |
| A6061 | 2700 | 896 |

## 注意

本シミュレータは教育・可視化を目的とした簡易モデルです。実機の冷却時間・温度を厳密に
予測するものではありません（軸方向の2次元分布、巻き方向の異方性、相変化等は簡略化しています）。
