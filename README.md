# アルミニウムコイル 冷却シミュレータ（3D・横置き片側送風）

巻き取られたアルミニウムコイルの冷却過程を、3Dモデルで可視化するブラウザアプリです。
単一の `index.html` で動作します（追加のビルド・インストール不要）。

![type](https://img.shields.io/badge/type-single--file%20HTML-blue) ![3D](https://img.shields.io/badge/3D-Three.js-orange)

## 使い方

1. `index.html` をモダンブラウザ（Chrome / Edge / Firefox / Safari）で開く
2. 「▶ 再生」を押すと冷却シミュレーションが始まります（既定値で中心まで 60°C ＝ほぼ全体が青に
   なるのにコイル時間で約 30 時間。計算速度を上げて短時間で観察できます）
3. マウスで回転・ズーム（ドラッグ／ホイール）
4. 「断面 表示」ボタンで切り欠き、内部（半径×幅の2次元温度場）を確認できます
5. 「コイル列数」を 1〜6 にすると、風が通り抜ける直列配置になり、全数が完了温度に達するまでの
   各コイルの温度推移がグラフに表示されます

> 3D描画ライブラリ Three.js を CDN（unpkg.com）から読み込むため、初回はインターネット接続が必要です。

## 形状・配置

- **ドーナツ型円柱**（バウムクーヘン／トイレットペーパー状の中空円筒）
- **横置き（eye-to-wall）**：コイル軸を水平にし、外周面を下にして設置
- **片側送風**：一方のフラット面（=風上面）に風を当てて冷却
- **流体的な流れの可視化**：細い粒子が流線に沿って流れ、①巻芯（内周）を通り抜ける流れ、
  ②外周を通り抜ける流れ、③端面に当たって内側へ曲がり巻芯へ抜ける流れ、
  ④端面に当たって外側へ曲がり外周へ抜ける流れ、を表現（風が強いほど速く流れます）

## 特長

- **温度カラーマップ**：青（低温）→赤（高温）
- **非対称冷却の可視化**：風上面が先に冷え、風下面・中心ほど冷えにくい様子が分かります
- **2次元・異方性 物理モデル**：半径方向と幅(軸)方向の熱伝導を別々に扱います
- **温度推移グラフ**：単一コイルでは中心・風上面・風下面、複数コイルでは各コイルの中心温度を表示
- **複数コイル直列送風**：最大6個を風の通り道に並べ、上流で温まった空気が下流コイルを冷やす過程と、
  全数が完了温度（既定60°C）に達するまでの時間をグラフ化
- **可変パラメータ**：合金種・初期/周囲温度・送風強さ（熱伝達係数 h）・
  半径方向 実効熱伝導率 kᵣ・幅方向 熱伝導率 k_z・放射率・コイル寸法（外径/内径/幅）・
  コイル列数・送風風量 ṁ・完了判定温度・計算速度

## 物理モデルの概要

コイルを半径方向 `NR=24`・幅(軸)方向 `NZ=16` のセルに分割した
**軸対称2次元有限体積法**で、各セルの熱収支を陽解法で時間積分します。

- **熱伝導（異方性）**：フーリエの法則
  - 半径方向 `Q = kᵣ · A · ΔT / dr`
  - 幅(軸)方向 `Q = k_z · A · ΔT / dz`
- **表面の放熱**：対流＋放射 `Q = [ h·(T − T∞) + ε·σ·(T⁴ − T∞⁴) ] · A`
- **片側送風の非対称境界条件**（風上面の h を基準とした比率・UIで調整可）
  - 風上面 1.0（直接衝突）／ 外周面 0.80 ／ 巻芯(内周) 0.70 ／ 風下面 0.30（後流）
  - **重要**：これらを同じ値にしても、外周/巻芯面の放熱は端面より小さくなります。
    半径方向 kᵣ が低いため熱が表面まで届かず（伝導律速＝高 Biot 数）、表面温度が下がって ΔT が小さくなるためです。
    端面は幅方向 k_z が高く内部から熱が供給されるので高温を保ち、よく放熱します。
  - 各面の瞬時放熱量[kW]は画面右の「放熱内訳」で確認できます（合計＝内部エネルギーの減少率に一致）
- **熱伝導率の異方性**：
  - 半径方向 kᵣ：巻き重なり部の空気層・酸化皮膜により実効値は無垢材より大幅に低下（既定 3 W/m·K）。
    → 「中心が冷えにくい」主因
  - 幅方向 k_z：幅方向は連続金属のため伝導が速い（既定はおおむね無垢材値）。
    → 軸方向の温度差は相対的に小さくなります（物理的に妥当な挙動）。値を下げると軸方向差が顕著に
- 時間刻みは安定条件から自動決定し、計算速度に応じてサブステップ化します

### 複数コイル（直列送風）の空気連成

風の通り道に N 個（最大6）を直列に並べると、空気は風上から順に各コイルで熱を受け取って昇温します。

- コイル k に入る空気温度 `T_air[k] = T_air[k-1] + Q_conv[k-1] / (ṁ·cp_air)`（`T_air[0]=外気温`）
- ここで `Q_conv` は対流による放熱（放射は除く）、`ṁ` は送風風量、`cp_air≈1005 J/kg·K`
- 下流ほど高温の空気を浴びるため冷えにくく、完了が遅れます（送風風量 ṁ が小さいほど顕著）
- 既定（h≈20, ṁ=8）では全数が60°Cに達するのは約31時間。上流コイルが冷えると空気も外気温へ戻るため、
  完了時刻の差は数時間程度に収まります（伝導律速のため。ṁ を下げると差は拡大）

## 注意

本シミュレータは教育・可視化を目的とした簡易モデルです。実機の冷却時間・温度を厳密に
予測するものではありません（巻き方向の循環流、接触熱抵抗の分布、相変化、ふく射の形態係数等は
簡略化しています）。
